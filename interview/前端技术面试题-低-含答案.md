# 前端技术面试题（低）含答案

不绑定具体业务项目。低档看日常写页面是否正确：JavaScript 行为、DOM 和 CSS、浏览器基础、React 常用写法。每题先让候选人写结果或改代码，再用答案核对。

一面建议抽 12 到 15 题。只背定义、对不上代码输出的，这题不算通过。

## 01 typeof 和数组

写出下面每一行的结果。

```js
typeof null
typeof []
typeof function () {}
Array.isArray([])
```

**答案**

结果依次是 `"object"`、`"object"`、`"function"`、`true`。

`typeof null` 是历史遗留，不能用它判断空对象。数组也是对象，`typeof []` 同样是 `"object"`，判断数组用 `Array.isArray`。函数的 `typeof` 是 `"function"`，这是少数能直接看出来的引用类型。

易错点：把 `typeof null` 说成 `"null"`，或用 `instanceof Array` 判断跨窗口的数组。iframe 里的数组，原型链不是当前页面的 `Array.prototype`，`instanceof` 会失败，`Array.isArray` 仍然可用。

## 02 == 和 ===

写出结果，并说明为什么。

```js
0 == '0'
0 === '0'
null == undefined
null === undefined
[] == false
```

**答案**

`true`、`false`、`true`、`false`、`true`。

`===` 不转换类型，类型不同直接是 `false`。`==` 会做抽象相等：字符串和数字比较时，字符串先转成数字，所以 `0 == '0'`。`null` 和 `undefined` 互相宽松相等，但和任何其他值都不宽松相等，包括 `0` 和 `''`。

`[] == false` 时，两边都会转成数字。`false` 变成 `0`，`[]` 先变成空字符串，再变成 `0`，所以是 `true`。业务代码里应使用 `===`。需要同时接受 `null` 和 `undefined` 时，用 `value == null` 这一种宽松比较是明确的例外。

## 03 var 循环

点击三个按钮，分别弹出什么？怎么改才弹出 0、1、2？

```js
for (var i = 0; i < 3; i++) {
  buttons[i].onclick = function () {
    alert(i)
  }
}
```

**答案**

三个按钮都弹出 `3`。`var` 只有一个函数作用域里的 `i`，循环结束后 `i` 是 `3`。点击发生在循环之后，三个函数读的是同一个 `i`。

改成 `let i`。`let` 在每次循环有一个新的绑定，点击时读到的是那一次的值。也可以在当次迭代里用立即执行函数把 `i` 当作参数传进去。不要只说“用闭包”，要能指出 `var` 只有一份绑定。

## 04 let 的暂时性死区

下面代码会不会打印 `a`？

```js
console.log(a)
let a = 1
```

**答案**

抛出 `ReferenceError`，不会打印 `undefined`。

`let` 和 `const` 从进入作用域到初始化完成之前是暂时性死区。这个阶段访问变量不会像 `var` 那样得到 `undefined`。`const` 还必须在声明时赋值，之后不能重新赋值，但对象的属性仍然可以改。

## 05 闭包计数

连续调用三次 `counter()`，输出是什么？为什么 `count` 没有被回收？

```js
function createCounter() {
  let count = 0
  return function () {
    count += 1
    return count
  }
}
const counter = createCounter()
```

**答案**

输出 `1`、`2`、`3`。内部函数保存了对外层 `count` 的引用，只要 `counter` 还在，`count` 就不会被回收。这就是闭包：函数加上它定义时所捕获的变量环境。

如果把 `counter` 置为 `null`，并且没有别的引用，这次创建的 `count` 才可以被回收。闭包不是泄漏。泄漏是指本该释放的 DOM 或大数据仍然被这个函数引用着。

## 06 this 指向

在严格模式下写出四个结果。

```js
function show() { return this }
const obj = { name: 'chek', show }
obj.show()
const fn = obj.show
fn()
show.call({ name: 'other' })
```

**答案**

`obj.show()` 的 `this` 是 `obj`。把方法拿出来 `fn()` 单独调用，严格模式下 `this` 是 `undefined`，非严格模式下是全局对象。`call` 把 `this` 显式设为传入的对象。

`this` 不由函数定义的位置决定，而由调用方式决定。对象方法、单独调用、`call`/`apply`/`bind`、`new` 是四类常见调用。构造调用时 `this` 是新对象。

## 07 箭头函数没有自己的 this

`obj.regular()` 和 `obj.arrow()` 分别能不能拿到 `'inner'`？

```js
const obj = {
  name: 'inner',
  regular() {
    return this.name
  },
  arrow: () => this.name
}
```

**答案**

`obj.regular()` 能拿到 `'inner'`，因为普通方法的 `this` 由调用者决定，`obj.regular()` 把 `this` 设为 `obj`。

`obj.arrow()` 拿不到 `'inner'`。箭头函数没有自己的 `this`，对象字面量也不会变成 `this` 的作用域。它捕获的是定义位置外面的 `this`：在 ES module 里是 `undefined`，访问 `this.name` 会抛错；在浏览器非严格的普通脚本里是 `window`，得到的是 `window.name`。`call` 和 `bind` 也不能改掉箭头函数已经捕获的 `this`。

对象方法如果要指向对象自己，写成普通方法或类的方法，不要写成箭头函数。

## 08 原型链

`child.say()` 是怎样找到函数的？`child.hasOwnProperty('say')` 是什么？

```js
function Parent() {}
Parent.prototype.say = function () { return 'hi' }
const child = new Parent()
```

**答案**

`child` 自己的属性里没有 `say`，所以 `hasOwnProperty('say')` 是 `false`。读取时沿着 `child` 的内部原型找到 `Parent.prototype`，在那里拿到 `say`。再往上是 `Object.prototype`，最后是 `null`。

`new` 做了四件事：创建新对象，把新对象的原型指向构造函数的 `prototype`，用新对象当 `this` 执行构造函数，如果构造函数没有返回对象，就返回这个新对象。

## 09 宏任务和微任务

写出打印顺序。

```js
console.log('A')
setTimeout(() => console.log('B'), 0)
Promise.resolve().then(() => console.log('C'))
console.log('D')
```

**答案**

顺序是 `A D C B`。

同步代码先执行完，所以先是 `A` 和 `D`。`Promise.then` 的回调是微任务，当前调用栈清空后立刻执行，所以 `C` 在 `B` 前面。`setTimeout` 是宏任务，要等这次微任务队列清空后才执行。

易错点：认为 `setTimeout(fn, 0)` 会立刻执行。它只是尽快排进宏任务队列，最少也会等到当前脚本和已排队的微任务结束。

## 10 微任务里再排微任务

写出打印顺序。

```js
Promise.resolve()
  .then(() => {
    console.log(1)
    return Promise.resolve(2)
  })
  .then(value => console.log(value))
console.log(3)
```

**答案**

顺序是 `3`、`1`、`2`。

同步先打印 `3`。第一个 `then` 是微任务，打印 `1`。`return Promise.resolve(2)` 会让后面的 `then` 再等这个 promise 完成，多一次微任务，所以 `2` 最后打印。不是 `1 2 3`，也不是 `3 2 1`。

## 11 去重并保持顺序

写一个函数，去掉数组里的重复原始值，保留第一次出现的位置。

```js
unique([1, 2, 1, 3, 2])
```

**答案**

```js
function unique(list) {
  return [...new Set(list)]
}
```

`Set` 按插入顺序保存，展开后就是去重且稳定的数组。对象不能靠 `Set` 做深度去重，`{a:1}` 两次出现是两个引用。需要按某个字段去重时，用 `Map` 记录已经见过的 key。

易错点：用 `indexOf` 双重循环可以做，但是 O(n²)；用对象当字典时，数字 `1` 和字符串 `'1'` 会变成同一个键。

## 12 浅拷贝

`copy.user.name = 'b'` 之后，`source.user.name` 是什么？怎样让两边互不影响？

```js
const source = { user: { name: 'a' }, tags: ['x'] }
const copy = { ...source }
```

**答案**

`source.user.name` 变成 `'b'`。展开运算符只复制第一层，`user` 和 `tags` 仍然是同一个引用。

彼此独立需要深拷贝。现代浏览器可以用 `structuredClone(source)`。它能处理普通对象、数组、Date、Map、Set，不能克隆函数和 DOM 节点。`JSON.parse(JSON.stringify(source))` 会丢掉 `undefined`、函数、`Symbol`，并且把 `Date` 变成字符串，循环引用会抛错。

## 13 map 和 forEach

`a` 和 `b` 分别是什么？

```js
const a = [1, 2, 3].map(n => n * 2)
const b = [1, 2, 3].forEach(n => n * 2)
```

**答案**

`a` 是 `[2, 4, 6]`，`b` 是 `undefined`。

`map` 返回新数组，长度与原数组相同。`forEach` 只遍历，返回值永远是 `undefined`，不能链式继续调用数组方法。两者都不会改变原数组，除非回调里去改元素对象的属性。想过滤用 `filter`，想累计用 `reduce`。

## 14 默认值什么时候生效

写出两个结果。

```js
function load(limit = 10) { return limit }
load(undefined)
load(null)
const { page = 1 } = { page: 0 }
```

**答案**

`load(undefined)` 是 `10`，`load(null)` 是 `null`。默认值只在参数是 `undefined` 或没传时使用，`null` 是一个明确传入的值。

解构同样只把 `undefined` 当成缺失。`page` 是 `0` 时，`0` 会被保留，结果是 `0`，不是 `1`。需要把 `null` 也换成默认值时，写 `value ?? defaultValue`。

## 15 ?? 和 ||

`0`、`''` 分别通过这两种写法得到什么？

```js
const count = input || 10
const count2 = input ?? 10
```

**答案**

`||` 在左边是假值时取右边。`0`、`''`、`false`、`NaN`、`null`、`undefined` 都会被换成 `10`。数量和空字符串经常是合法值，所以这里会出错。

`??` 只在左边是 `null` 或 `undefined` 时取右边。`0` 和 `''` 都会保留。可选链 `a?.b` 只在 `a` 是 `null` 或 `undefined` 时短路，不会挡住 `0`。

## 16 冒泡和捕获

点中子节点时，监听器的执行顺序是什么？怎样只让子节点处理？

```js
parent.addEventListener('click', onParent)
child.addEventListener('click', onChild)
parent.addEventListener('click', onCapture, true)
```

**答案**

顺序是捕获阶段的 `onCapture`，然后目标阶段的 `onChild`，再然后冒泡阶段的 `onParent`。第三个参数 `true` 表示捕获。

只想让子节点处理时，在子节点调用 `event.stopPropagation()`，父节点的冒泡监听就不会执行。捕获监听如果写在子节点之前，停止传播也来不及拦住已经跑过的捕获。`stopPropagation` 不阻止浏览器的默认行为。

## 17 事件委托

一万行表格，为什么通常不给每行绑一个点击？请写出父节点上的判断。

**答案**

每一行一个监听会增加内存，动态增删行时还要反复绑定。点击会冒泡，在 `tbody` 上听一次即可。

```js
tbody.addEventListener('click', event => {
  const row = event.target.closest('tr')
  if (!row || !tbody.contains(row)) return
  open(row.dataset.id)
})
```

`event.target` 可能是单元格里的图标，不能假定它就是 `tr`。用 `closest` 向上找。判断 `contains`，避免点到表格外面但冒泡路径异常的情况。

## 18 preventDefault

链接写成 `<a href="/report">`，点击时既要发埋点又不要跳转。该用哪个方法？

**答案**

用 `event.preventDefault()` 取消导航。不要用 `stopPropagation()`，它只打断 DOM 树上的传播，链接仍然会跳。

两者可以同时使用，但职责不同。表单提交、复选框切换、滚轮滚动都有各自的默认行为，要取消的是默认行为，不是冒泡。

## 19 盒模型

元素设了 `width: 100px; padding: 10px; border: 1px solid`。默认和 `border-box` 下，边框盒子的总宽度各是多少？

**答案**

默认 `content-box` 的 `width` 只量内容区，总宽度是 `100 + 20 + 2 = 122px`。

`box-sizing: border-box` 的 `width` 包含内容和左右 padding、border，总宽度是 `100px`，内容区只有 `78px`。组件库和页面重置通常全局使用 `border-box`，否则百分比宽度加 padding 会溢出父级。

## 20 外边距折叠

父元素没有边框和 padding，子元素有 `margin-top: 24px`。为什么看起来是父元素被推下去了？怎样让空白留在父元素内部？

**答案**

相邻块级盒子的垂直外边距会折叠成较大的那一个。子元素的 `margin-top` 和父元素的 `margin-top` 相遇后，空白跑到了父元素外面。

让父元素变成 BFC，或给父元素加 `padding-top: 1px`、`border-top`、`overflow: auto`。水平外边距不会折叠。flex 和 grid 子项之间也不会发生这种外边距折叠。

## 21 flex 子项被挤没

右侧是 `flex: 1` 的长文本，左侧固定 `200px` 的导航最后变成一条缝。原因和改法是什么？

**答案**

flex 子项默认 `min-width: auto`，最小尺寸不能小于内容的最小宽度。长文本把另一侧挤小。

给长文本那一列加 `min-width: 0`，并让内部文本 `overflow: hidden`。`flex: 1` 是 `1 1 0%`，表示可放大、可缩小、基础尺寸为 0，但 `min-width: auto` 仍会拦住缩小。左侧如果必须保持 200px，再加 `flex-shrink: 0`。

## 22 水平垂直居中

写一种让未知尺寸的盒子在父元素里居中的 flex 写法。

**答案**

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

父元素需要有高度，否则垂直方向没有多余空间。另一种是 grid：`display: grid; place-items: center`。已知尺寸才适合用绝对定位加负 margin。行内文字的单行垂直居中可以用 `line-height` 等于高度，但多行文字会失效。

## 23 z-index 不生效

子元素 `z-index: 999`，仍然被旁边的兄弟盖住。父元素有 `transform: translateZ(0)`。原因是什么？

**答案**

`transform` 不是 `none` 时，父元素成为新的层叠上下文。子元素的 `z-index` 只在这个上下文内部比较，不能越过父元素去和外面的兄弟比。

`opacity` 小于 1、`filter`、`position` 加非 `auto` 的 `z-index`、`will-change` 也都会创建层叠上下文。先看被盖住的元素最近的层叠上下文，而不是把数字一直加大。

## 24 选择器优先级

两条规则谁生效？

```css
#app .title { color: blue; }
.title { color: red !important; }
```

**答案**

文字是红色。`!important` 先于普通声明。都重要或都不重要时，再比优先级：行内样式高于 ID，ID 高于类、属性、伪类，这些高于标签和伪元素。同一层按个数相加，不是十进制进位，所以 11 个类也不会超过 1 个 ID。

优先级相同才看源码顺序，后写的生效。不要靠把选择器写得很长来压过别人，改结构后很容易失效。

## 25 em 和 rem

根字体 16px，父元素 `font-size: 20px`，子元素 `font-size: 2em` 和 `font-size: 2rem` 各是多少像素？

**答案**

`2em` 相对父元素的字体，是 `40px`。`2rem` 相对根元素，是 `32px`。

`em` 会层层相乘，嵌套三层 `1.2em` 会越来越大。组件内部的间距如果用 `em`，会跟着组件自己的字体变。页面级缩放才用 `rem`，并且运行时的根字体必须和构建工具假设的基准一致。

## 26 清除浮动的真正目的

父元素里的子元素都 `float: left`，父元素高度变成 0。写一种修复。

**答案**

浮动元素脱离普通流，父元素算高度时不再把它们算进去。给父元素建立 BFC：`overflow: auto`，或使用清楚浮动的伪元素。

```css
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}
```

现在的布局优先用 flex 或 grid，不必为了并排而浮动。若还在维护旧页面，要知道高度塌陷是因为脱离文档流。

## 27 什么操作会强制布局

下面的循环为什么慢？怎样改？

```js
for (const el of items) {
  el.style.width = el.offsetWidth + 10 + 'px'
}
```

**答案**

读 `offsetWidth` 会强制浏览器把之前的样式改动算成布局。循环里一次写、一次读，就会反复布局。

先把所有宽度读进数组，循环结束后再统一写；或者用 flex、grid 让浏览器自己分配宽度。`offsetWidth`、`offsetHeight`、`getBoundingClientRect`、`getComputedStyle` 都可能触发这种同步计算。`clientWidth` 同样会。

## 28 defer 和 async

两个外部脚本都依赖对方的函数。该用 `defer` 还是 `async`？

**答案**

用 `defer`。它并行下载，等文档解析完后按 HTML 里的顺序执行，并且在 `DOMContentLoaded` 之前。

`async` 谁先下载完谁先执行，顺序不稳定，适合统计脚本这种不依赖 DOM 和其他脚本的文件。都不写时，脚本会挡住 HTML 解析。模块脚本默认就是延迟执行的。

## 29 三种存储

登录 token、只在当前标签页使用的草稿、跨标签页的主题，分别适合放哪？

**答案**

token 不应该放进 `localStorage`，任何脚本都能读。更合适的是服务端设置 `HttpOnly`、`Secure` cookie，前端 JavaScript 读不到。低档如果还没做登录安全，也要知道 `localStorage` 会在刷新和关闭浏览器后保留，并且同站的 XSS 能把它拿走。

只在当前标签使用的草稿用 `sessionStorage`，关闭标签就没了，新开的同源标签不共享。主题这种不敏感、要跨标签保留的界面设置可以用 `localStorage`。`sessionStorage` 和 `localStorage` 都只存字符串，容量大约数 MB，而且是同步 API，大字符串会卡住主线程。

## 30 状态码

301、304、401、404、500 在前端分别表示要做什么？

**答案**

`301` 是资源永久换了地址，浏览器以后可以直接访问新地址。`302` 是临时的。前端路由里的跳转不是这两种状态码。

`304` 表示缓存仍可用，响应体为空，浏览器使用本地副本。`401` 表示没通过认证，通常要重新登录，不要把它当成普通失败 toast 后无限重试。`403` 是已经知道你是谁但没有权限。`404` 是资源不存在。`500` 是服务端错误，前端可以重试安全的读请求，但不能假定写请求没有成功。

## 31 CORS 里前端能做什么

本地页面请求 `https://api.example.com`，控制台说被 CORS 拦住。把请求改成 `no-cors` 能不能读到 JSON？

**答案**

不能。`mode: 'no-cors'` 得到的是不透明响应，JavaScript 读不到正文。跨域是否放行由响应头决定，前端不能自己加 `Access-Control-Allow-Origin`。

服务端要返回允许的来源。带自定义头或 `Content-Type: application/json` 的请求会先发 `OPTIONS` 预检。带 cookie 时，前端设 `credentials: 'include'`，服务端必须返回具体来源，不能是 `*`，还要 `Access-Control-Allow-Credentials: true`。

## 32 列表 key

用 index 当 key，删除第一项后，第二项输入框里的文字跑到了第一项。为什么？

**答案**

React 用 key 判断前后两次渲染是不是同一个组件。index 在删除后全部变了，原来 index 为 1 的状态被复用到了新的 index 为 0 的位置，输入框里的 state 就跟着错位。

key 要用数据自己的稳定 id。列表会重排、插入、删除时，index 一定不稳定。key 不要用 `Math.random()`，否则每次渲染都像全新组件，输入焦点和内部状态都会丢。

## 33 setState 后立刻读

点击后马上 alert 的数字是旧的还是新的？

```jsx
function Counter() {
  const [n, setN] = useState(0)
  return <button onClick={() => { setN(n + 1); alert(n) }}>add</button>
}
```

**答案**

alert 到的是点击前的 `n`。`setN` 不会马上改掉当前这次渲染里的常量 `n`。它安排一次新的渲染，下次函数执行才拿到新值。

连续两次 `setN(n + 1)` 可能只加 1，因为两次都读到同一个旧 `n`。要累计时写 `setN(value => value + 1)`。React 18 会把同一个事件里的多次更新合并成一次渲染。

## 34 useEffect 依赖

只在挂载时请求，eslint 却警告缺少 `userId`。强行留空数组会出什么 bug？

```jsx
useEffect(() => {
  fetchUser(userId).then(setUser)
}, [])
```

**答案**

`userId` 变化后不会再请求，界面一直是第一个用户。空数组的含义是效应不依赖任何变化，这和代码事实相反。

依赖里应写 `userId`。快速切换用户时，旧请求后返回，还要用清理函数或 AbortController 丢掉过期结果。eslint 的提示是在对依赖和闭包做检查，不是多管闲事。

## 35 受控输入

下面的输入框为什么打字后内容不变？

```jsx
<input value={text} />
```

**答案**

`value` 被写死后，输入框的显示完全由 React 状态决定，但没有 `onChange` 去更新 `text`，所以每次输入都被渲染回旧值。

受控写法是 `value` 加 `onChange`，状态放在 React 里。不需要 React 管理每个按键时，用 `defaultValue`，让 DOM 自己保存，这是非受控。同一时刻不要既传 `value` 又指望用户直接改 DOM。

## 36 条件渲染

`count` 为 `0` 时，页面出现了一个 `0`。原因是什么？

```jsx
{count && <span>有数据</span>}
```

**答案**

`0` 是假值，`&&` 的结果就是 `0`。React 会把数字 `0` 渲染成文本，但不会渲染 `false`、`null`、`undefined`。

改成 `count > 0 && <span>有数据</span>`，或用三元表达式明确给出 `null`。空字符串不会显示成文字，但 `0` 会。

## 37 class 和 style

为什么 JSX 里不能写 `class`，行内样式也不能写字符串？

**答案**

JSX 会编译成 `React.createElement` 的普通对象。`class` 是 JavaScript 保留字，DOM 属性名是 `className`。样式要传对象，并且属性用驼峰：`style={{ fontSize: 14, backgroundColor: 'red' }}`。数字形式的长度默认按 px 处理，`fontSize: 14` 就是 `14px`。

想保持普通 CSS，把类名写在样式表里，元素只接收 `className`。不要把一整段 CSS 文本塞进 `style`。

## 38 模块作用域

同一个页面引入两个脚本，都写了 `const API = '...'`。什么情况下会冲突？

**答案**

普通脚本共享全局作用域，第二个 `const API` 会因为重复声明抛错。`var API` 则会互相覆盖。

`<script type="module">` 每个文件有自己的作用域，只有 `export` 再 `import` 才能被别人用。模块默认延迟执行，并且严格模式。现代前端构建出来的业务代码是模块，不应再往 `window` 上挂业务函数。

## 39 NaN

`NaN === NaN` 是什么？怎样判断一个值是 NaN？

**答案**

结果是 `false`。NaN 表示无效数值，它和任何值都不相等，包括它自己。

用 `Number.isNaN(value)`。全局 `isNaN('abc')` 会先把字符串转成数字，结果是 `true`，容易误伤。`Object.is(NaN, NaN)` 才是 `true`。`Object.is` 和 `===` 的另一个差别是 `Object.is(-0, 0)` 为 `false`。

## 40 页面打开时发生了什么

用户在地址栏回车后，到看到文字，浏览器至少做哪些和前端有关的事？

**答案**

先解析 URL 并通过 DNS、TCP、TLS 拿到 HTML。解析 HTML 时遇到外链 CSS 会下载，CSS 会挡住首次渲染，避免没样式的内容闪一下。遇到普通脚本会停下解析去执行，`defer` 脚本则等解析完再按顺序执行。

然后构造 DOM 和 CSSOM，合成渲染树，计算布局，绘制像素。之后才轮到加载图片和解码。`DOMContentLoaded` 是文档解析完成，`load` 是样式、图片等资源也加载完成。前端性能优化要先分清时间花在请求、CSS、脚本还是布局，而不是只看一个总秒数。
