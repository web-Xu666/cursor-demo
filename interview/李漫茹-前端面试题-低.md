# 李漫茹 · 前端面试题（低）

车控 CHEK 高级前端，2023.07 至今。题只围绕两套系统：App 内嵌 H5（Taro、Zustand、SSE、F2、高德）和智驾评测云平台（Umi、Ant Design、ECharts、RBAC、地图回放）。本档 40 题，项目 16 题、技术 24 题。

一面用。先让她用 90 秒讲驾驶报告从打开到可交互的链路，听她会不会主动分开容器、接口、图表和埋点。然后从本档抽 12 到 15 题，项目和技术穿插。连续两题讲不出数据来源或失败样本，就停在这一档。

她抛出算法名、库名或简历上的百分比之后，立刻要参数、失败样本和替代方案。讲不出计时起点、样本来源或请求顺序，这道题记为未通过。

## 这一档在卡什么

| 题号 | 类型 | 现场在卡的能力 |
| --- | --- | --- |
| 1–6 | 项目 | 容器、桥、双品牌、发布和回滚是不是她做的 |
| 7–13 | 项目 | 首屏、图表、抽稀、海报、SSE 有没有口径和失败样本 |
| 14–16 | 项目 | 权限和取消请求是不是只停在界面 |
| 17–26 | 技术 | WebView、订阅、类型、布局、安全区，必须落到自己的代码 |
| 27–40 | 技术 | 401 并发、缓存、消毒、埋点、环境、加密的威胁 |

## 01 容器登录 · 项目

车控 App 里打开驾驶报告，和用户用系统浏览器直接打开同一个 H5 链接，登录态分别从哪里来？非 WebView 降级之后，哪些按钮还在，哪些接口会失败？

**追问**

降级是构建出两套页面，还是同一套代码里运行时判断？判断写在哪个函数？WebView 伪装 UA 时会不会误判成浏览器？

**判定**

要听到 token 的注入方（原生桥、cookie 或 URL）以及失败后的具体 UI。只说做了兼容、讲不出非 WebView 的鉴权，这题不算通过。

## 02 双端桥 · 项目

举一个你必须分 Android 和 iOS 写的桥。调用参数、成功回调、失败回调的时序是什么？哪一端出现过调用成功但回调永远不来？

**追问**

超时设了多少毫秒？超时后页面停在什么状态？用户再点一次，会不会发出第二次原生调用？

**判定**

要听到具体桥名、参数和超时。只背 addJavascriptInterface 或 WKScriptMessageHandler 的定义，视为没在这个项目里写过桥。

## 03 品牌分层 · 项目

CHEK 和汽车之家是一套代码。品牌是构建期定死，还是用户打开页面时才决定？主题色、接口域名、分享文案、静态图各在哪一层切换？

**追问**

汽车之家包里如果残留 CHEK 的接口域名，用户侧第一个可见症状是什么？

**判定**

要听到配置分层，而不是业务组件里散落 `if (brand)`。讲不出残留域名的症状，说明没有真的隔离过产物。

## 04 新品牌三天 · 项目

新品牌从 2 周缩到 3 天。这 3 天里仍然要人工改的文件有哪些？哪些你承诺只改配置？

**追问**

NutUI 和自研组件，谁走 CSS 变量、谁走 Sass？只改配置时，哪一类样式一定会漏？

**判定**

要听到残留的人工项。把 3 天解释成复制项目再改名，多品牌就不是配置，而是复制。

## 05 发布分段 · 项目

发布从 25 分钟到 7 分钟。把这 7 分钟拆成安装依赖、构建、传包、切换流量。你实际削掉的是哪一段，靠什么削的？

**追问**

两品牌并行时，共享的 node_modules 或 npm 缓存出过什么串包问题？

**判定**

要听到分段耗时和并行隔离。只给 25 到 7 这个总数，数字还停在简历上。

## 06 回滚与缓存 · 项目

一天发布 15 次。上线后驾驶报告白屏，回滚步骤是什么？已经打开页面的用户会加载到旧 JS 还是新 JS？

**追问**

index.html 和带 hash 的 JS，缓存时间分别是多少？index.html 被缓存时，回滚为什么会失败？

**判定**

要听到入口文件不能长缓存。只说 Jenkins 点回滚，没有处理过缓存。

## 07 首屏口径 · 项目

驾驶报告首屏 3.2 秒降到 1.4 秒。计时起点和终点分别是哪个事件？样本是实验室机、你自己的手机，还是线上用户？

**追问**

低端安卓的分布，和这 1.4 秒是不是同一批样本？

**判定**

要听到实验室和线上 RUM 的区别。把接口变快也算进这 1.8 秒、又说不清占比，先记下，中档再拆。

## 08 图表生命周期 · 项目

报告页多个 F2 图表用 IntersectionObserver 按需渲染。快速来回滑动，同一个图表会 init 几次？滑出视口后实例有没有 destroy？

**追问**

rootMargin 设了多少？设得很大时，你怎么证明按需仍然生效？

**判定**

要听到 init 和 destroy 成对，观察器在卸载时断开。只说用了懒加载、没有生命周期，泄漏还在。

## 09 抽稀保留 · 项目

轨迹抽稀之后，急刹点和危险点还在不在图上？你用什么规则保证这些点不被抽掉？

**追问**

阈值用的是屏幕像素还是地理距离？地图放大后要不要重新抽一次？

**判定**

要听到业务点保留规则。只说出 Douglas-Peucker、讲不出阈值和保留集，只是知道算法名。

## 10 海报失败 · 项目

html2canvas 海报成功率 99.5%。失败的那部分是什么机型、什么报错？跨域图片和自定义字体你怎么处理？

**追问**

生成期间主线程会卡多久？用户连点分享，会不会并发生成两张？

**判定**

要听到失败样本，以及代理、crossOrigin 或转 base64 其中一种跨域策略。没有失败日志的 99.5% 不能信。

## 11 首字拆段 · 项目

首字从 1.8 秒到 1.0 秒。连接建立、服务端首 token、前端解码、首次上屏各占多少？哪一段是你能改的？

**追问**

打点埋在 `reader.read` 第一次返回，还是埋在屏幕上出现文字？两者差在哪？

**判定**

要听到网络 TTFT 和渲染分开。把整个 0.8 秒都归功于前端解码，说明链路没拆过。

## 12 半包解码 · 项目

SSE 数据块可能切在一个汉字的 UTF-8 中间。你的解码器怎么处理这半个字符？切在 JSON 字段中间又怎么处理？

**追问**

用 TextDecoder 的 stream 选项，还是自己攒 buffer？多字节字符被丢掉时，用户看到什么？

**判定**

要听到 `stream: true` 或残包缓冲。每段直接 `JSON.parse`、没有半包处理，追问两轮就会对不上。

## 13 会话串扰 · 项目

弹窗切换导致会话串扰。按用户操作顺序讲一遍复现路径。两路请求的取消和消息列表分别绑在什么 id 上？

**追问**

取消发出之后，已经读到但还没 setState 的那段文本，还会不会写进新会话？

**判定**

要听到在途 chunk，而不只是 abort。关弹窗时清空数组，挡不住已经排队的更新。

## 14 路由守卫 · 项目

云平台把按钮隐藏之后，用户改本地路由还能不能打开页面？守卫写在路由、布局，还是每个按钮里？

**追问**

权限接口比页面渲染慢时，页面会先闪出内容再跳走吗？

**判定**

要听到路由守卫和按钮是两层，并且知道前端隐藏不是安全边界。只说条件渲染，层数不够。

## 15 角色编码 · 项目

角色编码保护防的是什么操作？谁来保证后端也校验同一个编码，而不是只靠前端禁用输入框？

**追问**

你怎么测改请求体里的 code 这种越权？测过没有？

**判定**

要听到保护的对象，例如内置角色不可改码、不可删。测试只停在 UI 禁用，就还没和后端对齐。

## 16 重复请求 · 项目

重复请求减少 50%。你怎么定义一次重复？用户连点查询，取消的是先发出的还是后发出的？

**追问**

报表轮询和用户手动刷新算不算重复？取消错了，页面会停在旧数据还是变成空白？

**判定**

要听到请求键（url 加参数）和保留哪一次。把所有相同 URL 都取消，会误伤轮询。

## 17 WebView 差异 · 技术

举一个在浏览器里正常、进 App WebView 才出问题的 Taro API 或样式。你怎么把原因定位到 Taro 运行时、WebView 还是业务代码？

**追问**

Taro 3 的 H5 组件最终渲染成什么 DOM？你在真机上用什么看这个 DOM？

**判定**

要听到具体 API 和定位路径。只说 WebView 兼容差，这题没有信息量。

## 18 订阅范围 · 技术

驾驶报告的图表数据和 AI 对话的 token 如果放在同一个 Zustand store，流式输出时图表会不会跟着渲染？你怎么验证？

**追问**

选择器返回新对象，和返回原始字段，渲染次数差在哪？

**判定**

要听到选择器的引用相等。建议拆 store，但说不清订阅，只是习惯拆分。

## 19 列表 key · 技术

行程列表的 key 用什么？如果后端删除后再复用旧 id，列表会出现什么错位？

**追问**

用 index 做 key，再把加载更多插到头部，哪一行的展开或勾选会串？

**判定**

要听到局部状态串行的具体症状。只背 key 要稳定、没有症状，继续往下追。

## 20 节流与卸载 · 技术

滚动时 100ms 节流后再 setState。节流函数写在组件函数体内部，每次渲染会不会新建计时器？你的项目里它实际写在哪？

**追问**

节流期间组件卸载，延迟的 setState 打到已卸载组件，你怎么处理？

**判定**

要听到 timer 放在 ref 或稳定回调里，并在清理函数里取消。背闭包陷阱但不知道写在哪，不算会。

## 21 配置类型 · 技术

品牌配置要保证 CHEK 必须有 primary 色和接口域名，缺一个就编译失败。这个类型你怎么写？

**追问**

配置最终来自 JSON 时，编译期类型还保护得了线上吗？

**判定**

要听到必填字段，并主动说出 JSON 需要运行时校验。所有字段都可选的 interface，没有约束力。

## 22 边界校验 · 技术

图表接口的 data 在类型上是 unknown。你在哪一层把它收成 F2 要的点数组？校验失败时页面展示什么，而不是白屏？

**追问**

多一个字段和少一个字段，处理一样吗？

**判定**

要听到校验在接口边界，失败有降级 UI。在图表组件里 `as` 断言，类型是骗过编译器的。

## 23 强制布局 · 技术

从用户点击切换车型，到 F2 重绘完成，哪一步会强制同步布局？你怎么在性能面板里看到它？

**追问**

先改 class 再读 offsetWidth，和先读再改，这一帧差在哪？

**判定**

要她指出自己页面上的一次读写交错。只背 reflow 的定义，这题不算。

## 24 rem 混用 · 技术

postcss-pxtorem 同时服务 375 宽的 H5 和 1920 宽的大屏时，根字体如果只有一个公式，移动端会怎样？

**追问**

你怎么让 Ant Design 的弹层不被 rem 放大？

**判定**

要听到根字体和选择器黑名单按端拆开。说全站 rem 就自适应了，大屏和 H5 会一起错。

## 25 细边框 · 技术

安卓 WebView 上 1px 边框发虚。你在项目里实际用的方案是什么？为什么不用把整条边框 scaleY(0.5)？

**追问**

圆角、虚线、四边不全的边框，这个方案哪一种会破？

**判定**

要听到自己用的那一种（0.5px、伪元素或 svg）和它的失效场景。三种方案名都背得出、不知道项目用哪个，是准备过的题。

## 26 安全区 · 技术

iOS 底部横条挡住分享按钮时，安全区数值从 CSS env 来，还是从原生桥来？安卓手势导航你怎么处理？

**追问**

桥给的安全区和 `env(safe-area-inset-bottom)` 不一致时听谁的？

**判定**

要听到这个项目的数据来源。两端都答用 env、却没在安卓上看过实际值，让她说出安卓上读到的数。

## 27 401 单飞 · 技术

token 过期时 5 个请求一起 401。刷新 token 会发出几次？其余 4 个是排队重放，还是直接失败？

**追问**

刷新也 401 时，怎么避免死循环？用户会看到几次登录跳转？

**判定**

要听到单飞和失败熔断。拦截器里刷新、但 5 个请求打出 5 次刷新，实现是错的。

## 28 缓存失效 · 技术

驾驶报告切到后台再回来，数据要不要重新请求？你用什么条件判断过期？

**追问**

用户在 App 里改了车辆设置再回 H5，H5 怎么知道缓存已经脏了？

**判定**

要听到过期条件或失效通知：可见性、桥事件或版本号。每次 onShow 都请求，或永远用缓存，都要她讲清代价。

## 29 图表选型 · 技术

同一条速度曲线，App 里用 F2，云平台用 ECharts。对调之后会先坏在包体积、触摸、大数据量，还是截图？

**追问**

F2 在 Taro 里画在 canvas 上吗？做分享海报时，这块 canvas 和 html2canvas 是什么关系？

**判定**

要听到选型理由和先坏的点都落在自己的页面。比较两家官网的特性表，不算做过选型。

## 30 地图白屏 · 技术

高德地图在 WebView 里白屏。你的排查顺序是什么？key、域名白名单、WebGL、混合内容，你实际踩中过哪一个？

**追问**

地图容器高度为 0，和 key 无效，症状有什么不同？

**判定**

要听到固定顺序和一次真实根因。上来就说看控制台，没有顺序。

## 31 富文本消毒 · 技术

模型回答里如果带 img 的 onerror，或者链接是 javascript:，你的渲染在哪一步去掉它？

**追问**

流式输出还没闭合标签时，危险片段会不会先出现在屏幕上？

**判定**

要听到白名单或消毒，并且知道流式半截 HTML 有一个窗口。说 React 默认转义、实际却走 HTML 渲染，前后矛盾，抓住这一点。

## 32 完成率定义 · 技术

会话完成率提升 42%。完成对应哪一个埋点？用户答到一半杀进程，算完成、未完成，还是不进分母？

埋点丢失时，完成率会偏高还是偏低？

要听到分子和分母。说用户觉得有用、却没有事件名，这个 42% 不能用。

## 33 滚动锚点 · 技术

上拉加载更早的对话时，怎么保证屏幕上正在看的那句话不跳动？

## 34 主题变量 · 技术

## 35 环境来源 · 技术

测试包打到预发接口这种事故，你怎么在构建阶段拦住？运行时用 location.host 判断，和构建时写死的域名，以谁为准？

本地 mock、测试、预发、生产，Axios 的 baseURL 到底读哪一个变量？

## 36 Mock 同源 · 技术

后端字段晚到两天。Mock 数据和 TypeScript 类型怎么绑在一起，避免 Mock 能跑、接真接口就崩？

真接口多一个字段、少一个字段，你的流程哪一种会先失败？

## 37 评审标准 · 技术

你评审一个 Taro 业务组件时，必看的三件事是什么？举一个你实际打回、后来证明打对了的例子。

## 38 卡顿口径 · 技术

帧率工具在 WebView 里和在桌面 Chrome 里，差在哪？

## 39 解压位置 · 技术

## 40 前端加密 · 技术

crypto-js 在云平台里加密的是哪段数据，密钥放在哪？密钥如果就在前端包里，这层加密防住了谁，防不住谁？
