## 01 换品牌后图表仍是旧颜色

根节点的 `--brand` 已经变成汽车之家的橙色，CSS 按钮也变了，ECharts 折线还是绿色。初始化代码如下。请写出切换品牌时要补的那一步。

```ts
const color = getComputedStyle(document.documentElement).getPropertyValue('--brand')
chart.setOption({ series: [{ type: 'line', lineStyle: { color } }] })
```

**追问**

只在页面加载时读一次颜色。用户不刷新，调用什么才会让折线变色？

**判定**

## 04 过期的流式写入

请补全：A 对话还在读流，用户打开 B。A 后面到达的块不能再进入 B 的消息列表。

```tsx

  const reader = res.body!.getReader()
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    const text = decode(value)
```

**追问**

`sessionRef.current = sessionId` 如果写在渲染期间，而不是在切换函数里，会有什么问题？

## 05 直接 push 不刷新

## 20 虚拟列表的窗口

对话列表渲染了全部 DOM，300 条之后滚动掉帧。每条高度固定 72。请写出视口起止下标的计算。

```tsx
function List({ items }: { items: string[] }) {

```

**追问**

滚动容器不是 window，而是里面的 `div`。`scrollTop` 从哪读？

## 31 链接白名单

模型文本用白名单渲染 `<a>`。请写出 `href` 允许通过的判断。下面这个链接必须失败。

```html
<a href="javascript:alert(document.cookie)">详情</a>
```

**追问**

`https://chek.com@evil.com` 这种链接，你的判断会不会放行？

**判定**

只允许 `http:` 和 `https:`，用 URL 解析而不是 `startsWith('https://')` 这种字符串判断。用户名在 `@` 前面的地址要按真正的 host 判断，不能只看前缀。

## 32 开关关掉时中断流

接口返回 `aiChat: false` 后，对话入口要消失。如果此时已经有一条 SSE 在读，请写出还要做什么。

```tsx
function Page() {
  const flags = useFlags()
  return flags.aiChat ? <Chat /> : null
}
```

**追问**

`useFlags` 每分钟轮询一次。组件卸载和开关变 false，都能走到同一次 abort 吗？

## 33 一张图出错不要白屏整页

## 34 测试不要断言 store 结构

## 35 导出按钮连点

导出接口要 3 秒。用户连点，下载了三份相同文件。请用请求中的状态把第二次点掉，并在结束时恢复按钮。

## 36 图表把页面顶下去

曲线接口返回前容器高度是 0，返回后突然变成 240px，下面的轨迹表格跳了一下。请改结构。

```tsx

  return <div style={{ height: 240 }}><F2Chart data={data} /></div>
}
```

**追问**

骨架和最终画布都是 240 高。数据为空时你还留不留这 240？

## 37 地图脚本何时加载

首页不需要地图，报告页需要。请写出动态加载的位置。不要在 `index.tsx` 顶层 import 地图 SDK。

用户从报告返回首页后，地图脚本还在内存里。这是加载策略的问题，还是实例没有 destroy 的问题？

## 38 表头不吸顶

评测表的表头写了 `position: sticky; top: 0`，滚动时仍跟着走。父级 CSS 如下。请指出原因并改。

```css
.table-wrap { overflow: hidden; height: 480px; }
thead th { position: sticky; top: 0; }
```

**追问**

真正滚动的是 `.table-wrap` 里面的另一个 div，而不是它自己。`sticky` 相对哪个滚动容器生效？

**判定**

祖先的 `overflow: hidden` 会让 sticky 失效。sticky 相对最近的滚动祖先，滚动必须发生在那个没有把 overflow 设成 hidden 的容器上。

## 39 滥用 will-change

对话列表每一行都加了 `will-change: transform`，希望滚动更顺。低端机反而更卡。请说明浏览器为此多做了什么。

```css
.message { will-change: transform; }
```

**追问**

合成层应该加在正在做动画的那一条，还是列表里的每一条？动画结束后要不要去掉？

**判定**

`will-change` 会让每一行都准备独立合成层，几百条会占大量内存。只加在当前动画元素上，结束后移除。

## 40 Fragment 的 key 放错位置

切换车型后，备注框的内容留在了下一种车型上。请改 key 的位置。

```tsx
function Editor({ carId }: { carId: string }) {
  return (
    <>
      <Remark key={carId} />
      <Curve key={carId} />
    </>
  )
}
```

`Remark` 内部有自己的 `useState` 草稿。

**追问**

如果两个子组件都需要在换车型时重置，key 放在父组件和分别放在子组件，效果有什么差别？

**判定**

`key` 要放在有状态的组件上，而且父级重新挂载时应把 key 放在 `Editor` 自身被使用的位置。Fragment 上的 key 不会重置里面那些没有正确 key 的状态。换 `carId` 时 `Remark` 必须重新挂载。
